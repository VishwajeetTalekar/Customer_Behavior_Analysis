---

## 📌 Project Overview

The **Customer Behavior & Shopping Insights Analysis** project is an end-to-end data analytics solution designed to help a leading retail enterprise understand consumer purchasing patterns, boost customer engagement, and optimize business strategies. By examining sales channels, demographic trends, shipping preferences, and promotional impacts, this project turns raw transaction data into strategic recommendations for executive decision-makers.

### Technical Pipeline & Execution
1. **Data Cleaning & Pipeline (Python):** Raw consumer transaction records were processed and transformed using Python (`pandas`). The cleaned dataset was structured and automatically ingested into a relational database using `SQLAlchemy` and `PyMySQL`.
2. **Relational Analytics & Querying (MySQL):** Using **MySQL Workbench**, a total of 14 business-focused SQL queries were designed and executed. The analysis incorporated advanced SQL techniques, including Common Table Expressions (CTEs), window functions (`ROW_NUMBER() OVER()`, `SUM() OVER()`), and conditional logic (`CASE WHEN`) to solve key business problems:
   - **Customer Segmentation:** Categorized buyers into *New*, *Returning*, and *Loyal* segments based on historical order volume.
   - **Product & Revenue Ranking:** Identified the top revenue-generating and highest-rated products within each category.
   - **Promotional & Financial Analysis:** Evaluated discount efficiency, shipping choice impacts (*Standard* vs. *Express*), and revenue distribution across age groups, genders, and payment methods.
3. **Interactive Reporting (Power BI):** A live connection between MySQL and **Power BI Desktop** was established to construct an interactive executive dashboard. Using DAX measures, dynamic slicers, and KPI cards, stakeholders can visually drill down into real-time demographic contributions and category trends.

🔍 SQL Analytical Queries Summary
The MySQL analysis answered 14 key business questions across revenue, demographics, customer segmentation, and product performance:

Q1. Demographic Revenue: Total revenue generated by male vs. female customers.

Q2. High-Value Discount Users: Customers using discounts who spent more than the average order value.

Q3. Highest Rated Items: Top 5 products with the highest average review ratings.

Q4. Shipping Impact: Average purchase amount comparison between Standard and Express shipping.

Q5. Subscription Value: Average spend and total revenue comparison between subscribers and non-subscribers.

Q6. Discount Reliance: Top 5 products with the highest percentage of purchases using discounts.

Q7. Customer Cohort Segmentation: Grouping customers into New, Returning, and Loyal tiers using CTEs.

Q8. Category Leaders: Top 3 most purchased products within each category using ROW_NUMBER().

Q9. Subscription Propensity: Analyzing if repeat buyers (>5 orders) are more likely to subscribe.

Q10. Age Revenue Breakdown: Contribution of each age demographic to overall sales revenue.

Q11. Category Revenue Leaders: Top 3 revenue-generating products per category using window functions.

Q12. Category Share: Percentage share of total revenue contributed by each product category.

Q13. Top Spenders: Identification of the top 10 highest spending VIP customers.

Q14. Payment Gateway Performance: Total revenue, order count, and average order value across payment methods.

⚙️ Setup & Installation Instructions
Prerequisites
Python 3.10+

MySQL Server 8.0+ & MySQL Workbench

Power BI Desktop

MySQL Connector/NET Driver (for Power BI)

1. Clone the Repository
Bash
git clone [https://github.com/vishwajeettalekar/customer-shopping-behavior-analysis.git](https://github.com/vishwajeettalekar/customer-shopping-behavior-analysis.git)
cd customer-shopping-behavior-analysis
2. Set Up Python Environment
Bash
python -m venv venv
# On Windows:
venv\Scripts\activate
# On macOS/Linux:
source venv/bin/activate

3. Run Data Ingestion Pipeline
Ensure MySQL Server is active on 127.0.0.1:3306, then run:

Bash
python python/data_pipeline.py
4. Execute MySQL Script
Open MySQL Workbench.

Open and run sql/customer_behavior_queries.sql.

5. Launch Power BI Dashboard
Open Power BI Desktop.

Open power_bi/Customer_Behavior_Dashboard.pbix.

Connect to your local MySQL database (127.0.0.1:3306 / customer_behavior).

💡 Key Business Recommendations
Optimize Discounting: High discount rates on low-margin products reduce overall profitability. Re-evaluate discount thresholds to target items with higher basket-size upsell potential.

Subscription Incentives: Because repeat purchase frequency strongly correlates with active subscriptions, introduce post-second-purchase incentives to convert returning buyers into subscribers.

Inventory Restocking: Prioritize restocking around top-performing category leaders identified in SQL Queries 8 and 11.
